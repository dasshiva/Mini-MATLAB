Mini MATLAB Help

A small guide to the currently supported MATLAB subset.

Back to Mini MATLAB

Getting started

  1. Write MATLAB-style code in the Code panel.
  2. Click Run to parse and evaluate it.
  3. Use plot to display a graph in the Graphs panel.
  4. Use Create, Open, and Save for basic script files.

The implementation runs in the browser. It is a focused subset, not full MATLAB.

Comments and statements

Comments begin with % and continue to the end of the line:

% This is a comment
x = 1;

Statements can be separated by a newline or a semicolon. A semicolon suppresses displayed output.

Numbers, variables, and constants

x = 5;
y = 2.5;
z = 1.2e-3;
a = pi;
b = e;

Names may contain letters, numbers, and underscores, but must start with a letter or underscore. The built-in constants are pi and e.

Arithmetic

Supported scalar operators:

a + b
a - b
a * b
a / b
a ^ b

Unary positive and negative values, parentheses, and standard operator precedence are supported.

Element-wise operators are available for vectors and matrices:

y = x .* x;
y = x ./ 2;
y = x .^ 2;

Vectors, matrices, and ranges

row = [1 2 3];
column = [1; 2; 3];
A = [1 2; 3 4];
x = 1:5;
y = 0:0.1:1;

Spaces or commas separate values in a row. Semicolons separate matrix rows. Matrix multiplication uses *.

Mathematical functions

The following functions are supported and can operate on scalar values or matrices:

sin, cos, tan, exp, log, sqrt, abs, floor, ceil, and round.

x = linspace(0, 2*pi, 100);
y = sin(x);

Additional functions:

  • linspace(start, stop, count)
  • zeros(rows) or zeros(rows, columns)
  • ones(rows) or ones(rows, columns)
  • size(value)
  • length(value)
  • sum(vector)
  • min(vector)
  • max(vector)

Plotting

Plot a vector against automatically generated one-based x-values:

y = [1 4 2 5];
plot(y);

Or provide both x and y vectors:

x = linspace(0, 2*pi, 100);
y = sin(x);
plot(x, y);

Plot appearance settings:

title('Sine Wave');
xlabel('x');
ylabel('sin(x)');
grid on;

Multiple plot calls create multiple plotted series. Plotly provides zooming, panning, hover values, and image export controls.

File controls

  • Create clears the editor and resets the graph message.
  • Open loads a local .m or .txt file.
  • Save opens a filename dialog and downloads the current code.
  • Run processes the current editor contents.

Example

% Plot a sine wave
x = linspace(0, 2*pi, 200);
y = sin(x);
plot(x, y);
title('Sine Wave');
xlabel('x');
ylabel('sin(x)');
grid on;

Current limitations

The current subset does not include conditionals, loops, user-defined functions, indexing, structures, cell arrays, complex numbers, symbolic math, or general MATLAB file I/O.
